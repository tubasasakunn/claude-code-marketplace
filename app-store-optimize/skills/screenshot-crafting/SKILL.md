# App Store スクリーンショット制作 (screenshot-crafting)

## 概要

ストアスクショは「アプリ画面の記録」ではなく**検索結果に3枚並ぶ広告**である。ユーザーは中央値7秒・2.4枚で判断し、スクロール率は約17%——つまり最初の3枚がほぼすべて。このスキルは、CONCEPT.md / DESIGN.md を持つアプリから、審査に通り・タップされるスクリーンショット一式を導出するワークフローを提供する。

成果物は `Idea/ddd_アプリ名/SCREENSHOTS.md`（設計書）と、それに基づく画像一式（iPhone 6.9" 必須 + iPad対応なら 13"）。

## 全体ワークフロー

上から順に進める。設計（何を・何と言うか）→ 制作（どう見せるか）→ 検証（通るか）の一直線。

1. **[00-overview.md](chapters/00-overview.md)** — 序章。スクショが果たす役割、判断の前提となる実証データ、全体像。最初に読む索引。
2. **[01-specs.md](chapters/01-specs.md)** — Apple公式仕様。必須サイズ・枚数・フォーマット・提出後の差し替えルール（PPO含む）。
3. **[02-storyboard.md](chapters/02-storyboard.md)** — セット全体のストーリーボード設計。3幕構成、枚数別の役割、カテゴリ別の勝ちパターン。
4. **[03-layout.md](chapters/03-layout.md)** — 1枚の中の構図。テキスト/デバイス配置、面積比、視線誘導、アクセント、アンチパターン。
5. **[04-copy.md](chapters/04-copy.md)** — 文言。コピーの型と実証データ、日本語の定番パターン、文字数・フォント基準。
6. **[05-review-safety.md](chapters/05-review-safety.md)** — 審査リジェクト回避。Guideline 2.3系の地雷と個人開発者が踏む罠。
7. **[06-automation.md](chapters/06-automation.md)** — 自動化。撮影→合成→ASC API/fastlaneでの提出パイプライン。

**設計が固まったら実際の画像にする工程は `/app-store-optimize:screenshot-build` が受け持つ。**
HTML+CSS で組んで Playwright で書き出す道具一式（端末モックへの射影変換、UI の切り出し、
複数枚にまたがる構成、画面上で位置を合わせるエディタ）とサンプルがそちらにある。
AI 生成で作るなら `/app-store-optimize:aso-appstore-screenshots`。

補助ドキュメント:
- **[CHECKLIST.md](CHECKLIST.md)** — 提出前の最終検証チェックリスト（仕様・デザイン・審査）
- **[FAQ.md](FAQ.md)** — 頻出の判断（横向き？何枚？フレーム有無？差し替え方法？）

## クイックリファレンス

### 作るべき画像（これだけ）

| 対象 | サイズ | 枚数 |
|---|---|---|
| iPhone 6.9"（必須） | **1290×2796** 縦（1260×2736 / 1320×2868 も可） | 5〜7枚 |
| iPad 13"（iPad対応時のみ必須） | **2064×2752**（2048×2732 も可） | 同構成 |

他の全サイズは自動スケール生成される。PNG/JPEG、言語×デバイスごと最大10枚。**縦向き必須**（検索結果に3枚見える。横だと1枚）。

### 5枚テンプレート（デフォルト構成）

```
1枚目: ヒーロー — 最大の価値提案ひとこと（16文字以内・太字・上部）
        NG: ログイン画面 / 空画面 / アプリ名の繰り返し / カテゴリで自明な説明
2枚目: 主要機能をベネフィット化「〜するだけで◯◯」
3枚目: 差別化機能 + UIズームアップ（ルーペ表現）
4枚目: サブ機能 or 使用シーン
5枚目: 社会的証明（★評価バッジ）。無ければ「完全無料」「広告なし」等の事実訴求
```

全枚共通: DESIGN.md のブランドカラー背景、実UIを画面の50%以上、テキストは面積の20%以下、キャプション位置は上下交互で単調さ回避。

### 日本語コピーの型（実アプリ検証済み）

| 型 | 例 |
|---|---|
| ◯秒で | 「2秒家計簿」「最短1分で登録完了」 |
| 〜するだけ | 「話すだけで想いが残る」 |
| かんたん・あんしん | 「かんたんに売り買い」 |
| これ一つで | 「資産管理もこれ一つで」 |
| 実績数値 | 「累計5,500万DL」※自社で証明可能な数値のみ |

1行16文字以内、ひらがな7:漢字3、ヒラギノ角ゴ W6/W3（またはNoto Sans JP太字）で階層化。抽象的な機能名よりベネフィット+数字が一貫して勝つ。

### 審査の三大地雷（詳細は 05）

1. **2.3.3**: スプラッシュ/ログイン画面のみNG。UI要素を省いた「盛り」もNG（実機の見た目そのまま）
2. **iPad手抜き**: iPhone画像の引き伸ばし流用NG。iPad実解像度で撮り直す
3. **2.3.7/2.3.9**: 価格・期間限定文言の焼き込みNG、実在人物でなく架空データ、根拠なき「No.1」NG

## 終了条件

- [ ] SCREENSHOTS.md に全枚の構成（レイアウト+文言）が書かれている
- [ ] 必須サイズ（6.9"、iPad対応なら13"も）の画像が枚数分ある
- [ ] CHECKLIST.md の必須項目をすべてパス
- [ ] 文言がsquintテスト（縮小表示で判読可能）を通る
