# Growth Playbook (2026) — 視聴最大化の運用ルール

Hioto の TikTok / Lemon8 写真カルーセル（日本語）のオーガニック再生を最大化する指針。
毎日のパイプライン（分析・生成・予約）と投稿スキルが**これを必ず満たす**こと。
出典・詳細は調査ログ参照（2025–2026のプラットフォーム挙動＋日本のマーケ媒体で裏取り）。

## 効くことの要点
- **配信は初動で決まる**：TikTok/Lemon8とも投稿後 **1〜2時間（Lemon8は「ブーストタイム」≈1h）** の反応速度で配信量が決まる。出したら初動を取りに行く時間に出す。
- **カルーセル優位**：写真カルーセルは単一画像/動画よりリーチ・保存・コメントが大きい（自社観測でも6枚=1枚の約2倍）。**5〜10枚で各スライドに価値**（フィラー禁止）。逆スワイプ（見直し）は強い正シグナル。
- **1枚目＝フック**が最重要。弱いと初動スワイプが落ち配信制限。文字は**短く・大きく・高コントラスト・和文ボールド**、固定スタイルで反復しブランド認識。
- **文字を詰め込みすぎない**（高文字密度スライドは嫌われ速攻スワイプ＝低滞在）。

## 投稿時間（JST）— 予約時に従う
- **TikTok**: 平日 7–9時 / 21時前後、**金・土 17–22時**（ゴールデン）。月曜は避ける。金土が最大チャンス。
- **Lemon8**: 朝7–8 / 昼12 / 夜21–23 でテスト（公式データ薄め＝自インサイトで確定）。
- 既定の予約時刻は **平日=21:10 / 金土=18:30** を基準にする（`schedule_lib.py` の TIME_RULES）。

## ハッシュタグ
- **TikTok 3〜5個**：ジャンル大1（#日記 / #vlog）＋ニッチ2〜3（#撮るだけ日記 等）。付けすぎNG。投稿後編集不可なので確定前に確認。
- **Lemon8 5〜8個**：ビッグ2／ミドル3／スモール2〜3。**内容一致を最優先**（無関係タグ・キャンペーン全部盛りは運営ピックアップされにくくNG）。**季節語・年号を1語**入れる（例「日記 2026」）。
  ※注意：Lemon8アプリの**入力UI上限は実測5個**だったことがある→ UI制限に当たったら5個に絞る。

## フック型（1枚目＋キャプション1行目）— 日本語
- 疑問形：「1年後、今日のこと覚えてる？」
- ターゲット明示：「日記が3日で続かない人へ」「写真フォルダがぐちゃぐちゃな人へ」
- 数字：「1日10秒で1年が残る」「30日続いた私の記録」
- ビフォーアフター：「日記アプリ全部挫折した私→これだけ続いた」
- 共感/common-enemy：「“ちゃんと書かなきゃ”がしんどい人へ（書かなくていい）」
- 損失回避：「知らないと損、撮った写真が勝手に日記になる方法」
→ 1枚目は短文フック1つ。長文は2枚目以降へ。

## 音源（TikTok）
- 写真投稿でも**トレンド/人気音源を付けると発見性UP**。TikTokは自動付与されるが、可能なら投稿フローでトレンド音源に差し替える（tiktok-post の編集画面で音源選択）。

## Lemon8 は「保存される」設計
- タイトル＝**数字＋アクション語**、サムネ＝パステル＋白文字、後で見返したくなる完結情報（使い方1枚ずつ/テンプレ/チェックリスト）。
- 保存率5%未満ならサムネ文字を拡大、本文冒頭を数字か疑問形に。

## 頻度
- 週3〜4回・**一貫性最優先**（ジャンル/デザイン固定）。毎日運用は是非が割れる→質を落とさない範囲で。トレンド時は集中投下。
  ※本運用は「毎日1本作り順次予約」だが、**質が落ちる日は無理に作らない/予約間隔を空ける**判断を上に置く。

## チェックリスト（投稿確定前に必ず）
1. 5〜10枚のカルーセルか／各スライドに価値があるか（フィラー無し）
2. 1枚目が強いフック（短文・大・高コントラスト・固定スタイル）か
3. キャプション1行目が数字/疑問形/「○○な人へ」で引けているか
4. TikTokタグ3〜5（大1＋ニッチ）／Lemon8タグ5〜8（大中小・内容一致・季節/年号1語）
5. 投稿時間が枠（平日21時前後 or 金土17–22 / Lemon8朝昼夜）に合っているか
6. （TikTok）トレンド音源を付けたか
7. （Lemon8）保存したくなる完結情報＋数字入りタイトルか
8. 2フィルター（撮影コスト足さない/アプリ内SNS化しない）を通っているか
