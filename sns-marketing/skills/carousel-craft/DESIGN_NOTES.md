## 確定ノート

- [2026-08-02][サムネ] ★★**「黒オーバーレイと白文字でワンパターン。サムネにバラエティが欲しい」**との指摘（[2026-07-27] の**再々発**）。実測すると 28投稿の表紙が **treat=dark 8/8（anki）**、`layout` 型は**0回**、`mode` 指定は**0箇所**だった。
  **なぜ守られなかったか（ここが本質）**：[2026-07-27] に置いた規範が「1投稿で暗幕は**2枚まで**」という**上限**の形をしていた。実際の骨格は `cover`＋`photo` でちょうど2枚に張り付き、**一度も上限を超えないので「3枚目からは別 mode」が一度も発火しなかった**。規範は完璧に守られていて、それでもワンパターンだった。しかも上限に当たる2枚が**表紙と2枚目＝いちばん見られる2枚**。
  **対応（3点）**：
  1. 表紙を **`variant`（文字組）× `treat`（写真の扱い）** の2軸に分解し、`treat` を **dark / light / duotone / paper / frame / band / edge** の7種で実装（`variant=card` は自前で紙パネルを敷くので8つ目の顔）。**9 variant すべてに自動で効く**（`_cover_base` が `Skin` を返し、variant は `K.ink`/`K.anchor()`/`K.sh()` を使う）。→ `templates/standard.py`
  2. 判定を**上限から「直近3投稿と違うこと」へ反転**し、markdown ではなく **`qa.py` の COVER-REPEAT で hard fail** させる（treat の被り・表紙写真の使い回し・variant+treat の完全一致）。規範文で足りないことは 2回証明された。
  3. 企画の**前**に叩く `scripts/cover_history.py` を追加（直近の表紙一覧＋「選べる treat」＋「一度も使っていない treat」）。
  **1投稿の中でバリエーションを散らす必要はない**（同じ投稿の中は揃っていてよい）。**投稿と投稿の間で散らす**のが目的。
