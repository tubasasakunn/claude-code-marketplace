# ios-app-guide

SwiftUI + SwiftData + Cloudflare Workers によるiOSアプリ開発のガイドラインスキル。
Filmi (mymovie) の開発プロセス（30コミット・8フェーズ）から抽出した再利用可能な知見。

## 使用方法

```
/ios-app-guide <質問 または 開発フェーズ>
```

## 使用例

```
/ios-app-guide 新しいiOSアプリの開発手順を教えて
/ios-app-guide SwiftDataのマイグレーション注意点
/ios-app-guide ナビバーの透過設定方法
/ios-app-guide デザインシステムの構築方法
/ios-app-guide Maestroでスクリーンショットを撮る方法
```
