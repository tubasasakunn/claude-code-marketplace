# skill-creator

Claude Code用のスキル（SKILL.md）を作成・修正するためのガイドスキル。

## 概要

スキルの作成プロセスを4フェーズで体系化し、高品質なスキル開発を支援します。

1. **要件確定** - ユーザー要件を固める
2. **情報構造化** - ファイル構成を設計
3. **構成設計** - フロントマター・セクション構成を決定
4. **スキル作成** - ファイルを作成・検証

## 使用方法

スキル作成について質問すると自動的に呼び出されます。

```
スキルを作成したい
SKILL.mdの書き方を教えて
フロントマターの設定方法は？
```

## 機能

- SKILL.md構成テンプレート
- フロントマター設定ガイド
- ファイル構成パターン
- 検証チェックリスト
