# plugin-guide

Claude Codeプラグインの作成・インストール・管理をガイドするスキル。

## 概要

プラグイン開発のための包括的なリファレンスを提供します。マーケットプレイス設定、カスタムコマンド、エージェント、フック、スキル、MCPサーバー、LSPサーバーの統合について説明します。

## 使用方法

プラグイン開発について質問すると自動的に呼び出されます。

```
プラグインを作成したい
MCPサーバーをプラグインに追加するには？
```

## 機能

- プラグイン構造の説明
- plugin.jsonの作成方法
- コンポーネント（skills, commands, agents, hooks, MCP, LSP）の追加
- マーケットプレイスへの公開
- チーム配布の設定
