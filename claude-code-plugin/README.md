# claude-code-plugin

Claude Codeの機能拡張スキル集。プラグイン開発とスキル作成をサポートします。

## インストール

```bash
/plugin install claude-code-plugin@tubasasakunn-marketplace
```

## スキル一覧

| スキル | 説明 | 呼び出し方 |
|--------|------|------------|
| [plugin-guide](skills/plugin-guide/) | プラグイン作成・管理ガイド | 自動（プラグイン開発について質問時） |
| [skill-creator](skills/skill-creator/) | スキル（SKILL.md）作成ガイド | 自動（スキル作成について質問時） |

## 使用例

### プラグイン開発

```
プラグインを作りたい
MCPサーバーをプラグインに統合するには？
マーケットプレイスへの公開方法
```

### スキル作成

```
スキルを作成したい
SKILL.mdの書き方を教えて
フロントマターの設定について
```

## 機能詳細

### plugin-guide

- プラグイン構造（plugin.json、コンポーネント配置）
- スキル、コマンド、エージェント、フック、MCP、LSPの統合
- マーケットプレイス設定と公開
- チーム配布の設定

### skill-creator

- 4フェーズワークフロー（要件確定→情報構造化→構成設計→作成）
- フロントマター設定ガイド
- ファイル構成パターン
- 検証チェックリスト
