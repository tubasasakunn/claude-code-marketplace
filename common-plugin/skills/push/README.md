# push

現在のブランチをリモートにpushするスキル。

## 概要

リモートとの状態を確認してから安全にpushを実行します。

## 使用方法

```
/push
```

手動呼び出し専用（`disable-model-invocation: true`）

## 実行手順

1. **現在の状態確認** - ブランチ名、未コミット変更、リモート取得
2. **リモートとの差分確認** - pushされるコミットを表示
3. **競合チェック** - リモートに新しいコミットがあれば警告
4. **Push実行** - `git push origin <branch>`
5. **結果確認** - 最終状態を表示

## 安全機能

- **force push禁止** - `--force`や`-f`は使用しない
- **未コミット変更チェック** - あれば先にコミットを促す
- **リモート更新チェック** - pullを先に実行するよう提案

## エラー時の対応

### リモートに新しいコミットがある
```bash
git pull --rebase origin <branch>
# その後、再度push
```

### 認証エラー
SSH鍵やトークンの設定を確認
