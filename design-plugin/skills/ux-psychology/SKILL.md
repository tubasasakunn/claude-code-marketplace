# UX心理学評価

UIスクリーンショットを心理学的観点から分析し、100点満点で採点する。

## 概要

8つの心理学カテゴリでUIを評価し、問題点と改善案を含むレポートを生成する。

---

$ARGUMENTS の画像を評価してください。

## 進捗チェックリスト

```
- [ ] Step 1: 画像読み込み
- [ ] Step 2: 8カテゴリ評価
- [ ] Step 3: 問題点抽出
- [ ] Step 4: スコア検証
- [ ] Step 5: レポート出力
- [ ] Step 6: 完了確認
```

---

## 評価手順

### Step 1: 画像を読み込む

Readツールで `$ARGUMENTS` を読み込み、UIを視覚的に分析する。

**完了条件**: 画像が正常に読み込まれ、UI要素が識別できる

### Step 2: 8カテゴリで採点

| カテゴリ | 配点 | 評価観点 |
|---------|------|----------|
| 認知・知覚 | 15点 | 認知負荷、選択的注意、視覚的階層 |
| バイアス活用 | 10点 | アンカー効果、フレーミング、親近性 |
| 行動誘導 | 15点 | ナッジ、デフォルト設定、段階的要請 |
| モチベーション | 10点 | 目標勾配、ゲーミフィケーション |
| 価値知覚 | 15点 | 美的ユーザビリティ、社会的証明 |
| 記憶・体験 | 10点 | ピーク・エンド、系列位置効果 |
| UX設計手法 | 15点 | 段階的開示、意図的な壁 |
| リスク回避 | 10点 | 決断疲れ、誘導抵抗 |

**完了条件**: 8カテゴリ全てに点数が付与されている

### Step 3: 問題点を全て抽出

発見した問題点を**漏れなく**リストアップする。

**完了条件**: 各問題点に改善案が付与されている

### Step 4: スコア検証

- 各カテゴリの点数が配点以下であることを確認
- 合計点を計算（100点満点）
- グレードを決定

**完了条件**: 合計点 = 各カテゴリの合計（最大100点）

### Step 5: レポートを出力

以下の形式で出力する。

### Step 6: 完了確認（フィードバックループ）

レポート出力後、以下を自己チェック:

1. **網羅性**: 8カテゴリ全て評価したか？
2. **根拠**: 各評価に心理効果名を明記したか？
3. **改善案**: 全ての問題点に改善案があるか？
4. **計算**: 合計点は正しいか？

**不備があれば該当ステップに戻って修正する**

## グレード基準

| グレード | スコア | 説明 |
|----------|--------|------|
| S | 90-100 | 卓越。心理学的原則を高度に活用 |
| A | 80-89 | 優秀。主要原則が適切に適用 |
| B | 70-79 | 良好。基本は押さえているが改善余地あり |
| C | 60-69 | 平均的。複数の問題点が存在 |

## 注意事項

- 問題点は**全て**指摘する。見逃しは許容しない
- 良い点も必ず言及する
- 改善提案は具体的かつ実行可能に
- 心理効果の名称を使用し、根拠を明確に
