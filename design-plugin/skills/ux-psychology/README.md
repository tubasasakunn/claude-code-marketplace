# ux-psychology

UXデザインを心理学的観点から100点満点で評価するスキル。

## 概要

8つの心理学カテゴリでUIを評価し、問題点と改善案を含むレポートを生成します。心理効果の名称を使用して根拠を明確にします。

## 使用方法

`/ux-psychology <画像パス>`

```
/ux-psychology screenshots/checkout.png
```

## 評価カテゴリ

| カテゴリ | 配点 | 評価観点 |
|---------|------|----------|
| 認知・知覚 | 15点 | 認知負荷、選択的注意、視覚的階層 |
| バイアス活用 | 10点 | アンカー効果、フレーミング、親近性 |
| 行動誘導 | 15点 | ナッジ、デフォルト設定、段階的要請 |
| モチベーション | 10点 | 目標勾配、ゲーミフィケーション |
| 価値知覚 | 15点 | 美的ユーザビリティ、社会的証明 |
| 記憶・体験 | 10点 | ピーク・エンド、系列位置効果 |
| UX設計手法 | 15点 | 段階的開示、意図的な壁 |
| リスク回避 | 10点 | 決断疲れ、誘導抵抗 |

## グレード基準

| グレード | スコア | 説明 |
|----------|--------|------|
| S | 90-100 | 卓越。心理学的原則を高度に活用 |
| A | 80-89 | 優秀。主要原則が適切に適用 |
| B | 70-79 | 良好。基本は押さえているが改善余地あり |
| C | 60-69 | 平均的。複数の問題点が存在 |
| D | 59以下 | 要改善。重大な問題が複数存在 |

## 出力形式

```markdown
# UX心理学評価レポート

## 総合スコア: XX / 100点
### グレード: [S/A/B/C/D]

## カテゴリ別評価
### 1. 認知・知覚 (XX / 15点)
**良い点:** ...
**問題点:** ...
**該当する心理効果:** ...

## 問題点一覧
### Critical (致命的)
### Major (重要)
### Minor (軽微)
```
