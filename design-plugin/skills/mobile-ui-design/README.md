# mobile-ui-design

モバイルアプリUI/UXデザインを6カテゴリで評価するスキル。

## 概要

スクリーンショットを受け取り、6カテゴリで採点して問題点と改善案を提示します。「ダサい」の原因を具体的に特定し、改善方法を提案します。

## 使用方法

`/mobile-ui-design <画像パス>`

```
/mobile-ui-design screenshots/home.png
```

## 評価カテゴリ

| カテゴリ | 主な観点 |
|----------|----------|
| タイポグラフィ | 本文16px以上、行間1.5倍以上 |
| レイアウト | 8ptグリッド、タッチ44pt以上 |
| 視覚品質 | 純黒回避、シャドウBlur=Y×2以上 |
| 色彩設計 | 60-30-10比率、コントラスト4.5:1 |
| 致命的エラー | はみ出し、重なり、状態矛盾 |
| プラットフォーム準拠 | iOS HIG / Material Design |

## 判定基準

| 条件 | 判定 |
|------|------|
| 80点以上 & 致命的エラー0件 | PASS |
| 80点以上 & 致命的エラーあり | CONDITIONAL |
| 60-79点 | NEEDS_WORK |
| 60点未満 | FAIL |

## 出力形式

```markdown
## 総合スコア: XX / 100点
### 判定: [PASS/CONDITIONAL/NEEDS_WORK/FAIL]

### カテゴリ別スコア
| カテゴリ | スコア | 判定 |
|----------|--------|------|
| ... | XX/16.67 | ◎/○/△/× |

## 問題点一覧
### [カテゴリ名] の問題（-X点）
- 現状: ...
- 改善案: ...
```
