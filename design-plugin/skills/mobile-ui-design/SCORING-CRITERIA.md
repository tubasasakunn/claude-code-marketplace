# 採点基準と減点ルール

各カテゴリ16.67点満点。問題発見ごとに減点。

---

## 1. タイポグラフィ（16.67点）

| 問題 | 減点 |
|------|------|
| 本文が16px未満 | -4点 |
| 重要情報が14px未満 | -3点 |
| 和文の行間が1.5倍未満 | -3点 |
| 欧文の行間が1.2倍未満 | -2点 |
| ジャンプ率が不明確（見出しと本文の差が小さい） | -2点 |
| フォントの混在が不統一 | -2点 |

---

## 2. レイアウト（16.67点）

| 問題 | 減点 |
|------|------|
| 8ptグリッドから逸脱（中途半端な数値） | -3点 |
| タッチターゲットが44pt未満 | -4点 |
| 画面端余白が16dp未満 | -3点 |
| 内部余白 > 外部余白（近接の法則違反） | -3点 |
| 要素間隔が不揃い | -2点 |
| 隣接ボタンの誤タップリスク | -2点 |

---

## 3. 視覚品質（16.67点）

| 問題 | 減点 |
|------|------|
| 純黒(#000000)使用 | -3点 |
| デフォルトシャドウ（Blur不足） | -2点 |
| 角丸の不一致（ネスト時の計算ミス） | -2点 |
| 要素の整列ずれ | -3点 |
| 中央揃えの乱用（長文） | -2点 |
| アイコンスタイル混在（Outline/Filled） | -2点 |
| アイコン線幅の不統一 | -2点 |

---

## 4. 色彩設計（16.67点）

| 問題 | 減点 |
|------|------|
| 60-30-10比率の崩れ | -3点 |
| アクセントカラーの過剰使用 | -3点 |
| コントラスト比4.5:1未満（通常テキスト） | -4点 |
| コントラスト比3.0:1未満（大型テキスト） | -3点 |
| ダークモードで影を使用（表面色でなく） | -2点 |
| 高彩度色の乱用（目がチカチカ） | -2点 |

---

## 5. 致命的エラー（16.67点）

**発見即減点。複数発生時は累積。**

| 問題 | 減点 |
|------|------|
| テキスト/要素のはみ出し | -5点 |
| 要素の意図しない重なり | -5点 |
| テキストの途中切れ（ellipsisなし） | -4点 |
| 意図しない巨大空白 | -3点 |
| プレースホルダー残存 | -4点 |
| 同一情報の値不整合 | -4点 |
| 状態の視覚的矛盾 | -4点 |
| フィードバック欠如（ボタンにタップ状態なし） | -3点 |
| ナビゲーション断絶（戻れない画面） | -4点 |

---

## 6. プラットフォーム準拠（16.67点）

### iOS

| 問題 | 減点 |
|------|------|
| Safe Area無視 | -4点 |
| iOS標準ナビゲーションパターン逸脱 | -3点 |
| SF Symbols以外の異質アイコン | -2点 |
| Dynamic Type非対応の固定サイズ | -3点 |
| セマンティックカラー未使用（固定色） | -3点 |

### Android

| 問題 | 減点 |
|------|------|
| Material Design 3ガイドライン逸脱 | -4点 |
| システムナビゲーション非対応 | -3点 |
| Edge-to-edge非対応 | -2点 |
| sp単位未使用（固定px） | -3点 |

---

## 採点ルール

1. **各カテゴリの最低点は0点**（マイナスにはならない）
2. **同一問題の複数箇所発見は1回のみカウント**
3. **致命的エラーは例外として累積可能**
4. **判断に迷う場合は厳しい方で採点**
