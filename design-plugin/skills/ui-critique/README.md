# ui-critique

UIデザインを100点満点で評価し、全ての問題点を徹底指摘するスキル。

## 概要

「なんとなくダサい」の原因を言語化し、具体的な修正案に変換します。7つの評価項目で採点し、批評用語を使って問題を明確に指摘します。

## 使用方法

`/ui-critique <スクリーンショット または コードパス>`

```
/ui-critique screenshots/profile.png
/ui-critique src/components/Card.tsx
```

## 評価項目

| 評価項目 | 重み | 満点 |
|----------|------|------|
| 視覚的階層 | ×2 | 20点 |
| 一貫性 | ×2 | 20点 |
| 余白・バランス | ×1.5 | 15点 |
| 配色・コントラスト | ×1.5 | 15点 |
| タイポグラフィ | ×1 | 10点 |
| アクセシビリティ | ×1 | 10点 |
| 現代性・洗練度 | ×1 | 10点 |

## 批評用語

| 用語 | 意味 |
|------|------|
| 目が滑る | コントラスト不足、視覚的階層の欠如 |
| 目に痛い | 高彩度色の隣接、補色のハレーション |
| うるさい | 余白不足、強調要素の乱立 |
| 違和感 | 一貫性の欠如 |
| 垢抜けない | デフォルト設定、過剰な装飾 |
| 刺さらない | エモーショナルデザインの欠如 |

## 評価原則

- **残酷なまでに正直に** - お世辞は不要
- **具体的に指摘** - 何がどうダサいのかを明示
- **良い点も認める** - 維持すべき要素は必ず挙げる
