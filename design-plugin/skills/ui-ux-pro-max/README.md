# ui-ux-pro-max

UI/UXデザインを10カテゴリで包括的に評価するスキル。

## 概要

100点満点で評価し、問題点を具体的に指摘します。50スタイル、21パレット、50フォントペアリング、20チャート、8スタックに対応。

## 使用方法

`/ui-ux-pro-max <screenshot/code/url>`

```
/ui-ux-pro-max screenshots/dashboard.png
/ui-ux-pro-max src/App.tsx
/ui-ux-pro-max https://example.com
```

## 評価カテゴリ（各10点満点）

| # | カテゴリ | 主な観点 |
|---|----------|----------|
| 1 | ビジュアル階層 | 情報優先度、視線誘導、CTA |
| 2 | タイポグラフィ | フォント選択、サイズ階層、可読性 |
| 3 | カラー設計 | コントラスト比、配色調和 |
| 4 | スペーシング | 余白の一貫性、8pxグリッド |
| 5 | インタラクション | hover/focus状態、フィードバック |
| 6 | アクセシビリティ | WCAG準拠、キーボードナビ |
| 7 | レスポンシブ | モバイル対応、44pxタッチターゲット |
| 8 | パフォーマンス | アニメーション時間、重いエフェクト |
| 9 | 一貫性 | スタイル統一、パターン再利用 |
| 10 | UXベストプラクティス | ローディング、エラー表示 |
